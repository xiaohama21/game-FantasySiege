# 星灯远征原创程序音频

本目录的十个 WAV 是为《星灯远征》编写合成算法后生成的原创声音，没有使用第三方录音、采样包、现成音乐、在线服务或旧项目音频。生成工具仅依赖 Python 标准库，可随本项目代码和本地学习版收录。它们不受 D69 角色素材的学习用途限制；此声明只覆盖本目录的程序音频。

在项目目录运行 `python tools/generate_audio.py` 可重建全部声音；默认输出始终位于新项目 `assets/audio/`。合成种子固定，`generated_manifest.json` 记录 PCM 格式、长度、峰值、均方根和 SHA-256，用于验证可复现性。

| 文件 | 用途 / 听感 |
|---|---|
| click.wav | 短暖铃，界面操作反馈 |
| summon.wav | 上扬星灯声，召唤确认 |
| hit.wav | 短低音与柔化噪声，命中反馈 |
| heal.wav | 清亮三音，治疗反馈 |
| pulse.wav | 上扬扫频与泛音，星灯脉冲 |
| warning.wav | 两次低铃，敌军重击预警 |
| victory.wav | 上行琶音，胜利与章节完成 |
| defeat.wav | 下行琶音，败局反馈 |
| train.wav | 三音上行，训练完成 |
| ambient.wav | 24 秒低密度星灯和声，营地/战斗氛围循环 |

所有文件为单声道 22050Hz / 16 位 PCM。短音效有起止包络，峰值低于满幅；氛围载波与调制在完整 24 秒内均为整数周期，循环接点连续，不每轮渐隐到静音。GameAudio 在营地稍降低播放音高，战斗使用原速，不叠加第二条音乐；音量通过独立 UserPrefs 的主/音乐/音效选项控制。八个固定短音效播放槽、同类节流以及一个音乐槽为节点上限。

无渲染的 PreferencesSmoke 会验证偏好隔离与失败行为、WAV 读取、循环、音量和播放池；真实听感与最终设置窗口截图由完整学习版的实际运行验收覆盖。

正常关闭前需 `await GameAudio.shutdown()`，先停止并释放播放器，再以弱引用确认混音器已释放实际播放对象，随后退出场景树。结束时每 20ms 异步检查，最长 1 秒；本机一次实际排空为 56ms，超时会记录 `error_message`，游戏过程中不阻塞。AudioShutdownSmoke 覆盖真实 WAV 循环与音效后的清理，外层详细日志必须同时无 `Leaked instance` / ObjectDB 警告；引擎 `--quit-after` 的强制结束会绕过正常关闭流程，保留为单独诊断。
