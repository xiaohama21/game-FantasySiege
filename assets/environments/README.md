# 星灯远征：原创环境插画

五张可编辑SVG由本项目原创路径、渐变和几何绘制构成，不使用旧项目或第三方背景素材。

| 文件 | 大小 | 用途 |
|---|---|---|
| `camp-route.svg` | 1280×720 | 灯塔营地的悬岛观测站、航路、星灯和前景石岸 |
| `rift-isles.svg` | 2560×720 | 第一章苔石残岛：断拱、晶岩分面、苔石铺面 |
| `brass-remnants.svg` | 2560×720 | 第二章黄铜遗迹：铜管、齿轮、铆钉铺面和导航站 |
| `lighthouse-camp.svg` | 180×230 | 暖金星灯基地，独立于完整两屏背景 |
| `lighthouse-rift.svg` | 180×230 | 紫色裂隙基地，仅出现在战场远端 |

环境以已接入的Q版厚描边人物为尺度：深靛夜色，青绿/铜灰低对比远景，暖金局部光源。石材与铜板使用侧面暗部、接缝和边缘亮面形成体积；地面是y507–510，人物活动区y390–510保持低对比。碎石与植物在y520以下。两章原画各覆盖完整2560宽度，端点灯塔独立放置一次，没有平铺重复基地。

WorldBackdrop在章节/宽度切换时配置静态Sprite2D，三张环境图与两基地图共享加载缓存；星点与脉冲在另一个动态绘制层。背景SVG无需每30Hz重新提交全部路径，也没有额外实时骨架或Viewport。营地只显示友方星灯，不显示敌方基地。

离线检查使用本机sharp/librsvg渲染到`reports/art_environment/*.png`并复核；它只证明SVG构图可解析。最终Godot导入、实际角色叠放、两屏相机、UI无遮挡和完整Main性能须等桌面空闲后另验，不能用离线图片代替真机验收。
