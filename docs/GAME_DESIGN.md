## 1. 方向

工作名可后续修改。魔法与机械共存的破碎大陆，异界英魂加入远征；保留关羽、赵云、诸葛亮、貂蝉、吕布，其余全部由 Spine 素材重新设计为架空身份。上述五名是异界英魂，不强制三国年代或魏蜀吴阵营；形象基线保留，战斗职责按对攻重新平衡。

横向单线双方基地；战前编队，局内消耗自动恢复的能量召唤单位，单位自主移动/交战，摧毁敌方基地胜利。非 PvP。重复召唤继承角色养成，每个实例独立生命/冷却/状态。多单位同屏、大量 Spine 动作和可辨识战线是核心。

## 2. 第一版范围

可运行独立原型：八名初始角色（五保留+三新设）、三场可玩关卡、胜负结算、独立存档和等级强化、Spine 素材浏览/动作查看。内容文档规划扩充角色、小兵、精英、Boss、章节关卡及来源关联；规划不等于已运行。具体数量由盘点后 CONTENT_PLAN 定稿。

0.1.1验收：八角色/五敌军/三关/13独立骨架已运行；BattleSmoke59项、ProfileSmoke23项、MainFlow五页截图与流程通过。一级混合队伍三关81.8/133.2/186.9秒胜利，空阵线均败局。64单位逻辑每步约1.93ms；GTX1050独立64骨架视觉压力测试平均38.36fps、p95约37.43ms，尚未满足最初60fps压力门槛，下一阶段优化并测完整战斗，不把视觉压力数据写成全战斗性能。

0.1.1.2便携基础包：完整原始资产、原生库与Godot程序本地随包提供，导入时过滤源缓存元数据；包内所有战场视觉为真Spine，13底模135原始动作均通过，主页/属性/编队/图鉴/战斗图片复核通过。该包是三关基础学习版，尚未达到ROADMAP的完整收集章节与最终性能验收。

局内六至八槽；自动收入基础每秒 18、开局 160、容量 400（均配置化）。近战前排、远程/范围输出、辅助各有用途，阵容与召唤节奏先成立，再扩展进化/技能。第一版不复制旧复杂天赋、装备、酒馆、军需、战宠或多货币。

## 3. 长线与内容

0.1.3继续完善战前准备：八关卡片可浏览敌情，敌军人数、计划出场、加强波次生命/伤害和Boss反制均来自当前实际配置及中央数值；当前编队按已保存等级和研修显示能力，缺口仅建议已契约候选。界面以敌军卡片、六项属性图标、短词条和重点反制替代重复段落，统一守线/治疗/减速/攻城等标识；浏览不写盘，不改变开战权限，不预测必胜。规则见BATTLE_BRIEFING。

0.1.3养成增量为英魂研修：十二英魂各有两条有明确代价的路线。已契约、Lv.3且首通第四关后，支付180星砂一次解锁该英魂两条路线；初始保留基础路线，之后在营地免费切换或恢复基础。不增加货币、抽卡和强制通关门槛。具体配方与验收见TRAINING。schema3以单一study_routes字典保存解锁权益及当前选择，schema1/2只补空字典，保留资源与所有既有进度；未知路线回基础且保留解锁权益，更高schema只读。

UnitStats统一计算研修后的护甲、射程、前摇、范围与最终技能，治疗量和减速时长仅应用一次智力；战斗开局深拷贝玩家等级及研修配方，敌军不应用玩家研修。多来源减速各自计时，弱效果只刷新自身，到期恢复其他仍有效效果，不能延长已到期强效果。

每角色拥有力量、敏捷、智力，并选择一个主属性。力量提高生命，敏捷提高出手与移动速度，智力提高魔法抗性与治疗/减速等效果，主属性额外提高所有伤害。等级同时提升基础生命/伤害及三属性，主属性成长更高，具体公式见CORE，由UnitStats唯一计算。第一版不引入随机洗点与装备堆叠；属性、成长和最终数值常显于角色详情，主属性作突出标记。

召唤费用、冷却、射程和职责保持身份；通关获得训练资源。低费用短冷却角色保持补线价值。后续阶段以新关卡/新敌人机制驱动收集需求，少量形态进化和技能强化优先。Boss威胁靠机制和轮廓，不仅放大模型或提高属性。

0.1.2范围：保留八名初始角色，新增四名通过明确首通解锁的英魂，共十二名。两章八关，延续原前三关；第2/4/6/8关各解锁一名新英魂，首通额外星砂与角色只发一次，重访仍有固定训练收益。旧schema1档根据既有cleared回补已达成的角色解锁，不补发重复货币。出战最多八名，训练与编队只能使用已解锁英魂；未知/未拥有ID不能进入阵容。

现阶段合计十二玩家、九敌军、21套Spine来源资产（20个导出名家族，含机偶A/C变体）；第二章引入独立机偶/司炉/Boss族。用户地图反馈定稿：战场宽2560px，基地x100/x2460，视野1280px；鼠标左键在战场拖动、边缘移动或左右方向键平移；手动操作暂停自动跟随，按钮可恢复跟随战线。HUD保持固定。地图与逻辑坐标统一世界空间，表现转为屏幕空间；双方行军倍率配置化并重测关卡时长。

新增“星灯脉冲”：P或按钮，消耗80能量、35秒冷却，对前线最近敌军周围180px施加90真实伤害、1.2秒晕眩、向敌方后推60px（Boss减至25%），取消被命中敌军尚未结算的攻击。无敌军或暂停/终局时失败不扣资源；其价值为打断重击与争取补线时间，独立于角色技能。Boss至少有显式重击预警、半血阶段和反制窗口，脉冲给玩家即时操作手段。

等级继续按角色三属性成长，不加入随机装备/多重货币。后五关配置推荐等级并按实测养成资源验证可达，新增角色分别提供独特的守线/破甲/控制/攻城用途。最终关胜利展示章节结尾，集齐十二英魂后仍可重访尝试新编队。

逻辑保持60Hz；视觉通过手动骨架时钟和优先级降频优化，交战关键单位60Hz，远离交战单位30Hz，位置与命中均按原逻辑推进。保留1×/2×/暂停语义。目标真机普通24单位接近60fps，64压力场景p95帧时低于33.33ms；实际测量以完整场景为准，原始性能结果保留历史。

0.1.3最终配置候选使用Mobile渲染、Safe线程、托管原生Mesh刷新；所有人数使用两组低优先级采样，最多12个关键实例60Hz。配置在project.godot显式声明，由SpineActor与SiegeBattle共同读取；性能报告逐帧核验实际托管人数、关键人数和分组，与包内生产配置一致。正常可见窗口全300帧、24/64完整Main、2×回归及21来源220动作双视口差图仍须实际通过，才可标成最终学习包验收。

## 4. Spine 优先

源库全量登记编号、导出名、皮肤、动画、纹理、网格/路径/deform、缺失文件与许可。素材选择先按现成动作适配职责，再设计新身份；同底模可换皮/染色/缩放/光环/描边，必须关联配方和消费者。小兵、精英、Boss至少有轮廓/装备/特效与行为中的两种区别；同素材族先后教学。

骨架数据共享，单位实例独立 AnimationState；战斗逻辑与视觉分离，命中只由逻辑时点触发，Spine事件供校准，避免重复伤害。原生扩展缺失时用占位，不能把占位通过标为 Spine通过。性能预算先定双方合计64活单位、最多12个完整英雄；性能结果以真机测量为准。
