# 角色与关卡内容计划

> v0.1 · 2026-11-18 · GDD v0.1.0 / 程序0.1.1.0

用户保留身份：关羽、赵云、诸葛亮、貂蝉、吕布。其他角色、小兵、精英、Boss为架空新设计。完整内容表由全库编号/皮肤/动作盘点后补齐，必须包含源文件链接、配方、原/新身份、用途、出现关卡与验证状态。

第一版八可用角色：五保留＋铁卫/烬羽射手/符文医师。可玩三关：裂隙前哨（近战补线）、燃烬长廊（范围/射程）、黑曜城门（Boss压线）。关卡敌人ID、配方与出兵时间表采用同一resources配置；后续章节规划不得混作已实现内容。

角色/敌人素材不够可换皮、缩放、光环、描边，但每个消费者登记完整配方、至少两条可辨识差别与行为职责，避免仅换名/颜色。先教学普通兵，再组合精英，最后Boss复用已教学机制并增加明确阶段预警与反制窗口。
