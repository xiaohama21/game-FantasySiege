## 1. 内容方向与实现边界

破碎大陆的残岛漂浮在深靛色星海中，远征队用琥珀星灯连接失落航路。地图与菜单采用暖白羊皮纸、深靛夜空、黄铜机械、青绿符文；战场可同时出现剑盾佣兵、灵体、机械和异界英魂。首版保持关羽、赵云、诸葛亮、貂蝉、吕布五个用户指定身份，将其设定为异界来客；其余人物采用独立架空名称。原导出名只作素材溯源，不出现在玩家界面。

首版 `0.1.1.0` 的数据范围为八名玩家角色、五种敌军、三场关卡。首版开始时八名角色均可用，让玩家直接比较补线、突刺、范围、减速、治疗与重击的用途；后续收集系统再逐章开放新职责。首版不宣称十二关、形态进化或技能分支已实现。

当前 `0.1.2.0` 扩充为十二名可收集玩家角色、九种敌军、两章八关，共二十一套源编号资产及visual ID，覆盖二十个导出名家族；057/059为同一机偶家族的A/C皮肤，不重复计为独立底模。保留最初八名初始角色和原三关身份；第2、4、6、8关首通分别解锁星槌卫士、绞弩炮手、月灯术士、灵契兽卫。配置完成与战斗、存档、视觉、可达成长验收分别记录。后续形态进化和技能分支仍是规划。

所有八关设置world_width=2560，基地位于x100与x2460，地面y510；战场横向超过视口，通过鼠标和左右键移动镜头，HUD保持固定。同一关对双方使用move_speed_multiplier=1.45，让宽地图具有行军与调度空间，同时避免只有长时间等待。波次仍从敌基地出兵，首版不引入中途瞬移或未经教学的侧翼出生。

本文件中的“已配置”表示完成消费数据及来源关联；Spine 结构转换、原生加载、动作、朝向、视觉及性能验收由 `SPINE_PIPELINE.md` 与报告分别记录。“候选”只表示盘点与可适配性建议。素材源文件和原声明保留于本机，未经商用授权；Git 同步代码、设计和导入工具，运行素材按本机学习版本接入。

## 2. 三属性与首版成长

每个战斗单位有力量、敏捷、智力及一个主属性。`attributes` 为一级值，`attribute_growth` 为每级增长，单位数据中的 hp、damage、attack_interval 和 speed 都是未计算三属性的基础值。

- 力量提高最大生命，主属性同时提高攻击。
- 敏捷提高攻速及移动速度，主属性同时提高攻击。
- 智力提高魔抗和技能强度，主属性同时提高攻击。

实际公式及升级资源在 `CORE.md` 定义，由 `UnitStats` 统一计算；UI、战斗与测试必须使用相同出口。角色定位决定主属性，不能为追求统一稀有度让所有角色只加攻击。等级先增强既有职责，费用、召唤冷却、射程和伤害类型保持身份。后续进化才考虑改变技能或承担不同职责，成长值不能伪装成已实现的技能树。

当前技能是自动攻击或自动辅助的职责名称，不是需要手动释放的额外大招。八角色技能名称分别为青龙横扫、银枪连刺、星阵束流、流光缚影、陨星重斩、盾卫守线、烬羽长射、符灯回春。`skill_name` 与 `skill_description` 常显时必须注明“自动”，描述基础射程/范围/前摇/减速/治疗条件；受智力或等级变化的数值不能伪装成固定最终值。
