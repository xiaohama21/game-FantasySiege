# 收集、养成与存档

> v0.2 · 2026-11-18 · GDD v0.3.1 / 程序0.1.2.0
> v0.2：未保存胜利奖励保留重试入口，未来schema仅浏览且禁止发起新战斗。
> v0.1：十二角色拥有权、八关收益、schema2迁移与降级保护。

Catalog.playable_roster按units的playable标识读取全部玩家身份；initial_roster仍为八名初始角色。四名新英魂由2/4/6/8关首通各解锁一个。未拥有者可查看完整属性/技能及解锁关卡，不能训练、召唤或加入编队。最多八名出战，至少一名。

关卡按前关通关解锁，begin_run只为已解锁关生成会话。rewards.credits为每次胜利固定收益；first_clear_credits只首次通关发放；unlock_units为通关获得的角色。一次有效run只结算一次，写盘失败保留重试会话，不增加内存资源/拥有权/通关记录。失败/放弃无收益。奖励预览与实际结算读取同一配置，记录last_award帮助UI显示本次获得。

勝利后奖励尚未保存时，营地、Esc、重开或切页不得静默放弃run；界面提示先重试领取，保存成功才继续离开。ProfileStore.can_modify为未来版本保护的公共只读状态；高于当前schema仅可浏览，关卡入口、训练及编队操作禁用，begin_run也直接拒绝发起会话。

schema2字段：schema、credits、levels、cleared、roster、owned、transactions。读取schema1时保留原始资源、等级、编队和通关，补足八名初始拥有权，并根据cleared推导已达成的新角色；不回补额外首通货币。迁移只发生在内存，下一次成功事务写入schema2，备份仍可恢复旧schema1。更高schema禁止覆写，旧程序也能用未来schema保护拒绝写入新档。

训练成本40+当前等级×20，最高20级；等级属性由UnitStats统一计算。拥有/解锁只有集合增加，不消耗重复角色碎片。首通收益足以培养主要队伍到后期推荐等级，重访供试用其他角色，不依赖体力、抽卡或随机装备。

验证覆盖schema1迁移、首通/重访差别、同run重复领取、未拥有训练/编队拒绝、阶段锁、失败事务、重启拥有权回读和未来schema原始字节保护。章节结尾已点亮全部八关，仍可重访并用新角色重新编队。
