漂浮残岛以星灯连成远征路线，玩家在灯塔营地整备，召唤异界英魂和机械/魔法居民驱逐裂隙军团。深靛天空、低饱和青绿远景、琥珀星灯为场景主体；界面用暖白纸页、清晰深色字、细线边框与少量彩色职责徽章。已有Spine角色保持完整轮廓，地面光圈/特效连接不同素材画风。

首页常显章节进度与各关出征/重访入口，导航为远征、英魂、编队、图鉴。关卡卡提供名称、威胁、推荐应对和奖励，按通关顺序解锁。角色卡有姓名、职责、等级、主属性和简述。角色详情同时显示力量/敏捷/智力、成长、最终生命/伤害/攻速/射程/费用/召唤间隔，并说明当前训练成本。主属性使用“·主”和强调底色，与三属性数值同时常显；主属性额外贡献伤害的规则由中央计算及中文说明统一表达。

编队最多八人，点击可加入/移出，最低一人；最终保存成功后才确认编队改变。图鉴为中文英魂/敌军百科，常显姓名、职责、三属性、最终数值、技能效果、出现关卡及Boss反制；同时提供原生Spine动作与朝向查看。素材编号和兼容实现信息留在来源文档与开发工具，不进入战斗操作流程。

战斗视野1280×720、地图2560px。顶部显示双基地生命、关卡、能量与当前战线；主战场地面y510，基地x100/x2460；底部八张召唤卡有姓名、职责、能量成本与冷却覆盖。快捷键1—8召唤，空格暂停，F切换速度，P释放脉冲，Esc返回营地；按钮支持鼠标与触屏。战场用实际Spine行走、攻击、受击和死亡，飘字/攻击光效来自逻辑事件，绝不触发伤害。

胜利后显示奖励和首通进度，可继续下一关或返回营地；失败显示可执行建议并支持重试/整备。退出和重开释放旧战斗，暂停及终局停止召唤。保存失败显示具体提示并允许重试结算，不能重复领取。

首版背景、灯塔、资源/属性标记采用仓库原生SVG或Godot绘制；不沿用旧项目HUD布局。学习版优先使用Spine动画，缺失资源必须在素材页与报告标记，不用未验证占位冒充成品美术。后续围绕可读轮廓、攻击预警与击打反馈扩充动画和音效。

0.1.2：远征页分两章各四关，章节常显标题；关卡列出推荐等级、首通奖励、新英魂解锁及威胁/反制。十二英魂与编队用滚动列表，未解锁可查看属性/效果及解锁关卡，训练/加入按钮禁用。技能名称、三属性和成长继续常显，不能仅放tooltip。胜利弹窗区分首通额外奖励、重访奖励与新增英魂，最终关有明确远征结尾。

战场右上按钮“星灯脉冲 [P]”常显能量费用/冷却；顶部提示重击预警，脉冲命中前线显示青绿环与打断文字。暂停和终局不可用。底部仍八个召唤槽，角色数量增加通过战前编队选择，不挤入更多局内卡片。

战场2560×720，玩家看1280视野。战场区域按住左键拖动，鼠标靠左右边缘或←/→按键连续移动；所有操作夹紧边界且不会改变战斗位置/结果。默认跟随最前玩家/近处交战线，开场不跳至空白中央；手动操作关闭跟随，顶部“跟随战线”可恢复。资源/双基地生命/召唤/暂停固定屏幕，飘字和脉冲按世界位置转换，暂停也可查看地图。

摄像机交互区域y164–526，鼠标左右24px边缘与左右键以650px/s平移；左键拖动按实际位移。松键/松鼠标停止，鼠标在HUD和底部召唤卡上不触发边缘滚动。地图底部的小型视野滑条可快速定位；跟随按钮常显当前手动/跟随状态。第二章远景用黄铜轮廓和紫靛夜色区分，地图延展不重复左右基地。

世界骨架使用z10–29，飘字z60；屏幕界面整体z100，结算遮罩与纸页在screen内按绘制顺序覆盖。战斗单位不得穿过结算奖励、操作按钮或规则文字；实际胜利图为必要检查。

0.1.3：营地常显设置/操作指南，局内设置在地图底栏；弹窗暂停并关闭恢复原状态。百科英魂/敌军分类，姓名选择不含技术ID，左侧属性/技能/反制/出现关卡、右侧裁切预览与六动作/双朝向。技能完整中文名称、效果与实际治疗/减速等量常显。故事在开场天空面板可读，首关另有三页可跳过教程。HUD每0.1秒刷新，飘字固定24复用，模态期间地图/战斗键不穿透。

## 角色与环境美术补充（用户反馈，0.1.3范围）

- 十二英魂的静态透明肖像由各自visual_id的真实待机姿态生成，沿用skin/tint/native_facing/foot等配方，裁切保留头部、武器与主要轮廓；不从纹理图集硬裁未组合部件。工具显式记录原生加载、图像非空、来源配方和输出哈希。派生PNG放assets/portraits，忽略Git，包构建包含它们；生成采用后台离屏渲染，不占前台。
- 英魂列表与编队卡并列肖像和姓名/职责/等级/主属性，选中卡有琥珀边框；详情顶部约150px角色图配靛青展示窗，属性与技能文本保持完整。局内八槽保留当前总体占位，肖像约58×70px，姓名/费用/状态重新排版，不能因按钮禁用而完全看不清角色。图鉴延续动作预览，展示窗增加相同灯光/底座。
- 静态肖像只用TextureRect，不新增八个持续更新Spine或SubViewport。缺图用清楚的轮廓占位并保留姓名，最终验收要求十二肖像全部加载；角色预览和战斗配方一致。
- 环境新增仓库原生SVG插画层与Godot绘制：深靛天空的远岛/薄雾、苔石断拱/石桥、灯塔营地的悬岛航路、第二章齿轮/管道/黄铜平台。侧面阴影、石缝、铜板接缝和小型暖色窗口形成体积；远景降低饱和度/对比度，中景轮廓与人物厚线相近。
- 人物活动区y390–510维持清晰，主地面仍y510；新增高耸物体放远景或基地附近，近景植物/碎石限定在y520以下。世界两屏构图连续且不重复两端基地；营地采用独立景物排列，纸页可读。
- 全局配色、肖像展示框、基地灯光与脚下阴影共同连接人物与环境，不大面积覆盖人物原纹理。静态环境层只在章节/宽度改变时配置，不为每帧创建节点；完整性能门槛保持。
- 验收：英魂/编队/召唤/图鉴/营地/两章背景真实截图复核，姓名/技能/费用/冷却无遮挡；十二肖像非空并与所选身份一致；包内再次验收。用户当前使用桌面时可后台生成离屏图，主窗由启动器隐藏并保持最小化，force_draw(false)刷新子视口；不能设置Godot主窗visible=false。离屏只验证合成画面，前台输入与性能另验。

研修页沿用深靛营地、琥珀强调与暖白纸页；左侧为十二角色选择，右侧常显角色肖像、当前路线、三属性与最终生命/伤害/护甲/射程/速度/间隔/前摇及技能。下方并排两条路线，逐条用中文显示收益与代价和该路线最终关键值；未解锁可查看但不可切换。解锁条件显示已契约、Lv.3、第四关首通、180星砂各自状态，成功保存才确认扣费；解锁后提供免费恢复基础和免费切换。导航五项采用紧凑间距，设置及指南仍清楚可达。后台图覆盖未解锁、已解锁基础、两类激活路线和未契约状态，离屏不计前台性能。
